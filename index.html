Sobre el Proyecto

Project Automata es una iniciativa académica creada para demostrar conocimientos en diseño web, publicación de sitios en línea y utilización de herramientas modernas de desarrollo.

Tecnologías Utilizadas

HTML5

Base estructural moderna y semántica para aplicaciones web.

CSS3

Diseño adaptable con una experiencia visual moderna.

GitHub Pages

Publicación gratuita de sitios web estáticos.

Dominio Personalizado

Implementación de identidad digital propia.

Objetivos

Diseño Web

Crear interfaces modernas y atractivas.

Publicación Online

Desplegar contenido accesible para cualquier usuario.

Automatización

Explorar soluciones tecnológicas eficientes.

Aprendizaje Continuo

Aplicar conocimientos adquiridos durante la formación.
